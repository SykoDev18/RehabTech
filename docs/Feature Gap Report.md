## Priority Roadmap

Ordering rationale: pain-level Firestore persistence (P-1) is the spine — therapist dashboard (T-3), PDF reports (T-2), and any cross-role analytics depend on it. Camera lifecycle (S-3) is a stop-the-bleeding fix during active sessions. Patient appointment viewer (P-4) closes a visible patient↔therapist information gap and the data already exists.
